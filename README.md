## ```.env``` Structure

```bash
# Hack Club Authorisation
NEXT_PUBLIC_HACKCLUB_CLIENT_ID=
HACKCLUB_CLIENT_SECRET=

# Slack Authorisation
SLACK_ACCESS_TOKEN=
SLACK_REFRESH_TOKEN=

# Database Integration
MONGODB_URI=

# CDN API Key
CDN_API_KEY=

# Redirect URIs
NEXT_PUBLIC_REDIRECT_URI=
```
